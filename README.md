# Strait_Hormuz_act

Repositori ini berisi analisis data dan pemodelan *Machine Learning* terkait Krisis Selat Hormuz 2026. Proyek ini berfokus pada proses ekstraksi informasi, pembersihan data (*data cleaning*), visualisasi, serta penerapan algoritma *Clustering* untuk menemukan pola di dalam dataset.

## 📂 Struktur Repositori

- `2026_Strait_of_Hormuz_Crisis_.ipynb`: *Jupyter Notebook* utama yang mencakup proses persiapan data, *Exploratory Data Analysis* (EDA), dan analisis tren terkait krisis.
- `Clustering_Hormuz_crisis.ipynb`: *Notebook* yang secara khusus berfokus pada penerapan model *Unsupervised Machine Learning* (Clustering) untuk mengelompokkan data berdasarkan karakteristik tertentu.
- `README.md`: Dokumentasi utama proyek.

## 🛠️ Teknologi & Library yang Digunakan

Proyek ini menggunakan **Python** beserta beberapa *library* utama untuk manipulasi dan analisis data:
- **Pandas**: Untuk pengolahan data tabular, penanganan *missing values*, dan *indexing*.
- **NumPy**: Untuk komputasi numerik.
- **Seaborn & Matplotlib**: Untuk membuat visualisasi data yang informatif.
- **Scikit-Learn**: Untuk implementasi algoritma *Clustering* dan evaluasi model.
